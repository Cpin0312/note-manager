# ノート管理（Note Manager）

Windows 向けの、フォルダごとにノートを管理・編集する道具です。`index.html` 1枚だけで動き、インターネットにはつなぎません（完全オフライン）。

## 使い方

1. `index.html` を **Microsoft Edge** か **Google Chrome** で開きます（ダブルクリック、またはブラウザにドラッグ）。
2. 初回は「フォルダ選択」を押して、ノートを置く親フォルダを選びます。「ファイルの編集を許可」を聞かれたら許可します。
3. 次からは前回のフォルダが開きます。ブラウザを閉じたあとは「前回のフォルダを開く」を1回押します（ブラウザの決まりで、許可を取り直すため）。
4. 別のフォルダにするときは「フォルダ選択」を押します。

- 左の木でフォルダを選んで「新しいフォルダ」「新しいノート」を押すと、そのフォルダの中に作ります。新しいノートは `.md` です。
- 文字のファイル（UTF-8）なら拡張子に関係なく開いて編集できます。画像や Word など文字でないファイル、Shift_JIS のファイルは灰色で、開きません（壊さないため）。
- 木のファイルやフォルダを**右クリック →「削除」**で消せます。消す前に、名前（フォルダなら中のファイル数）と「元に戻せません」を出して確かめます。フォルダは中身ごと消えます。
- **ファイル検索**（左の一覧の上の欄）：ファイル名と中身の両方で、選んだフォルダ全体（下のフォルダも）から探します。1ファイル1行で、［名前］か［中身］の印がつき、中身で当たったときは最初に当たった行を添えます。押すと開きます（中身のときはその行）。左の一覧も、親のフォルダを開いてそのファイルに印を付け、見える所までスクロールします。検索の欄と結果は残るので、続けて別の結果も押せます。入力が止まってから探し始めます。文字でないファイルと 5MB より大きいファイルの中身は読みません。
- **文字の検索・置き換え**（「文字の検索・置き換え」ボタン、`Ctrl+F`、`Ctrl+H`）：今開いているファイルだけが対象です（ほかのファイルは左のファイル検索で）。画面の上に窓が出て、タイトルをドラッグで動かせ、`Esc` か × で閉じます。
  - 「探す」欄：編集画面の今の中身（未保存の変更も含む）を探し、結果は行番号とその行です。押すとその行に移ります。`Enter`／↓ で次、`Shift+Enter`／↑ で前の当たりへ。
  - 「正規表現」「大文字小文字」の切りかえがあります。正規表現がまちがっていると赤で知らせます。
  - 操作を選んで「実行」を押すと、すぐに編集画面の中身が変わります（確かめや見本は出ません）。結果は「〇 行を…」と1行で出ます。ディスクにはすぐ書かないので「● 未保存」が付き、`Ctrl+Z` で戻せます。よければ `Ctrl+S` で保存してください（改行の形と BOM は元のまま）。
    - **置き換え**：「探す」を「置き換え」欄の文字に。正規表現のときは `$1` などが使えます。
    - **行の削除**：探す文字に当たった行を消します。
    - **行マージ**：上下が全く同じ行を1行にまとめます。
    - **Ltrim／Rtrim**：行頭／行末の半角スペース・全角スペース・タブを消します。
    - 探す文字があれば当たった行だけ、空ならファイル全体が対象です（置き換えと行の削除は、探す文字が要ります）。
  - 押せないとき（ファイルを開いていない・MD表示中・探す文字が要る）は、その理由を窓の下に短く出します。
- **MD表示**（編集画面の上のボタン）：今のファイルを Markdown として整えて見せます（見出し・箇条書き・番号付き・太字・斜体・コード・リンク・引用・表・水平線・チェックボックス）。表示中は入力と窓の操作（置き換えなど）はできず、検索はでき、当たった所に色が付きます。保存はできます。未保存の変更も含めて表示し、「編集に戻る」で戻ります。ファイルを切りかえても表示のままです。ファイルの中の HTML は動かさず文字で見せ、リンクは別のタブで開きます（`javascript:` などは無効）。
- **名前の変更・移動**：
  - 右クリック →「名前の変更」で、今の名前の入った欄が出ます（`Enter` で決め、`Esc` でやめる）。
  - ファイルやフォルダを、別のフォルダ（いちばん上も）へドラッグすると移動します。右クリック →「移動…」で移動先を選ぶこともできます。移動の前に確かめます。
  - 同じ名前があるとき、Windows で使えない名前、フォルダを自分の中へ入れる移動は断ります（上書きしません）。フォルダは中身ごと動きます。
  - ブラウザの `move()` が使えればそれで動かし、使えないときはコピーして中身（大きさ・バイト）が同じことを確かめてから元を消します。途中で失敗したら元は消さず、画面に出します。
  - 開いているファイル（やそれを含むフォルダ）を動かすときは、未保存の変更があれば先に保存するか聞きます。動かしたあとも開いたまま、新しい場所で保存でき、左の一覧の印も合わせます。
- 左の一覧と右の編集のあいだの**仕切りをドラッグ**すると、一覧の幅を変えられます（180px から、編集の場所が 320px 残るまで）。幅は覚えて、次も同じ幅で開きます。
- 保存は `Ctrl+S` か「保存」ボタン。改行の形（CRLF / LF）と BOM は元のまま保ちます。
- 保存していない変更があると「● 未保存」が出て、ほかのノートへ移る・ページを閉じるときに確かめます。保存に失敗したら赤い帯で知らせ、書いた文は画面に残ります。

## 対応ブラウザ

| ブラウザ | 対応 |
|---|---|
| Microsoft Edge（パソコン版 86 以降） | 対応 |
| Google Chrome（パソコン版 86 以降） | 対応 |
| Firefox / Safari / スマホのブラウザ | 非対応（フォルダを直接読み書きする File System Access API がないため。開くと案内が出ます） |

ファイルは選んだフォルダに直接保存されます。ブラウザの中には、選んだフォルダの「場所の覚え」だけを残します（IndexedDB）。

## うまく選べないとき

ブラウザは「ドキュメント」「デスクトップ」「ダウンロード」そのものや、Windows のシステムのフォルダを選ばせないことがあります。その中に「ノート」などのフォルダを作って、それを選んでください。

## 確かめ（開発用）

Mac / Windows で Google Chrome と Node.js があれば、ヘッドレスの Chrome でロジックを確かめられます（Mac の Chrome の場所を使っています）。

```
node test/test.mjs    # 作成・編集・保存・CRLF/BOM・失敗の表示・ファイル検索・文字の検索と置き換えの窓・MD表示・名前の変更と移動・削除・一覧の幅など（127.0.0.1:8765 で配る）
node test/test2.mjs   # file:// で本物のフォルダの木・IndexedDB・起動し直したときのボタン
```
