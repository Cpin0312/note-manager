# ノート管理（Note Manager）

Windows 向けの、フォルダごとにノートを管理・編集する道具です。`index.html` 1枚だけで動き、インターネットにはつなぎません（完全オフライン）。

## 使い方

1. `index.html` を **Microsoft Edge** か **Google Chrome** で開きます（ダブルクリック、またはブラウザにドラッグ）。
2. 初回は「フォルダ選択」を押して、ノートを置く親フォルダを選びます。「ファイルの編集を許可」を聞かれたら許可します。
3. 次からは前回のフォルダが開きます。ブラウザを閉じたあとは「前回のフォルダを開く」を1回押します（ブラウザの決まりで、許可を取り直すため）。
4. 別のフォルダにするときは「フォルダ選択」を押します。

- 左の木でフォルダを選んで「新しいフォルダ」「新しいノート」を押すと、そのフォルダの中に作ります。新しいノートは `.md` です。
- 文字のファイル（UTF-8）なら拡張子に関係なく開いて編集できます。画像や Word など文字でないファイル、Shift_JIS のファイルは灰色で、開きません（壊さないため）。
- 保存は `Ctrl+S` か「保存」ボタン。改行の形（CRLF / LF）と BOM は元のまま保ちます。
- 保存していない変更があると「● 未保存」が出て、ほかのノートへ移る・ページを閉じるときに確かめます。保存に失敗したら赤い帯で知らせ、書いた文は画面に残ります。

## 対応ブラウザ

| ブラウザ | 対応 |
|---|---|
| Microsoft Edge（パソコン版 86 以降） | 対応 |
| Google Chrome（パソコン版 86 以降） | 対応 |
| Firefox / Safari / スマホのブラウザ | 非対応（フォルダを直接読み書きする File System Access API がないため。開くと案内が出ます） |

ファイルは選んだフォルダに直接保存されます。ブラウザの中には、選んだフォルダの「場所の覚え」だけを残します（IndexedDB）。
